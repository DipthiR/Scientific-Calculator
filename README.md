# Scientific Calculator

This is a Python-based Scientific Calculator built using the `tkinter` library for the graphical user interface (GUI). The calculator supports basic arithmetic operations as well as scientific functions such as sine, cosine, tangent, logarithm, and square root. The calculator also includes the functionality for exponentiation and parentheses to allow complex expressions.

## Features

- **Basic Operations**: Addition, Subtraction, Multiplication, Division
- **Scientific Functions**: Sine (`sin`), Cosine (`cos`), Tangent (`tan`), Logarithm (`log`), Square Root (`sqrt`)
- **Exponentiation**: Power operation (`^`) is supported and translated to `**` in Python syntax.
- **Parentheses**: Supports parentheses for complex calculations.
- **Clear Button**: Clears the input.
- **Error Handling**: Displays an error message if the calculation is invalid.
  
## Requirements

- Python 3.x
- `tkinter` library (comes pre-installed with Python)

## How to Run

1. Ensure you have Python 3.x installed on your system.
2. Save the Python code (provided above) into a file, e.g., `scientific_calculator.py`.
3. Open a terminal (Command Prompt or terminal emulator) and navigate to the directory where the file is saved.
4. Run the script with the following command:
   ```bash
   python scientific_calculator.py
## How to Use
1. The calculator window will appear with a display screen at the top and buttons for numbers, operators, and scientific functions.

2. Use the number and operator buttons to build a mathematical expression.

3. Use the function buttons (sin, cos, tan, log, sqrt) to insert scientific operations into your expression.

4. Press = to compute the result of the expression.

5. Press C to clear the input screen.

6. The result or error will be displayed on the screen.

## Example Usage
For example:

If you input sin(30) and press =, it will compute the sine of 30 degrees (in radians).

If you input sqrt(16) and press =, it will compute the square root of 16.

You can also input 3 + 5 * (2 - 1) and it will compute the result accordingly.
